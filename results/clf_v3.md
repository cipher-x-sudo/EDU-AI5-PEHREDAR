# Classifier v3 (Gemini data) evaluation

All numbers come from `results/clf_v3_metrics.json` (generated by `scripts/run_v3_evaluation.py`). Non-English sets are Gemini machine translations, not the human test set. Thresholds: chosen on dev at 2% benign FPR; nothing tuned on test.

## Conclusion

In plain terms: on roman_ur, routed_v3 over-blocks 6.9% of benign overrefusal prompts vs DeBERTa 47.0% (routed_v2 11.0%), with test recall 61.3% vs DeBERTa 60.5% at test FPR 2.3% vs 8.0%; per-row correctness differs significantly (McNemar p<1e-6; routed_v3 right where DeBERTa wrong 672, the reverse 61); on ur, routed_v3 over-blocks 8.8% of benign overrefusal prompts vs DeBERTa 97.1% (routed_v2 18.3%), with test recall 59.0% vs DeBERTa 89.3% at test FPR 5.6% vs 77.7%; per-row correctness differs significantly (McNemar p<1e-6; routed_v3 right where DeBERTa wrong 1549, the reverse 48); on mixed, routed_v3 over-blocks 9.5% of benign overrefusal prompts vs DeBERTa 42.2% (routed_v2 18.9%), with test recall 65.8% vs DeBERTa 59.2% at test FPR 2.3% vs 7.0%; per-row correctness differs significantly (McNemar p<1e-6; routed_v3 right where DeBERTa wrong 598, the reverse 69). On English, routed_v3 sends text to DeBERTa, so it keeps DeBERTa's behaviour (test recall 68.5%, overrefusal FPR 5.5%); v3 alone on English has recall 71.6% and overrefusal FPR 9.1%. All non-English sets are Gemini machine translations (review verdicts machine-suggested), not the human test set, so these numbers estimate rather than prove behaviour on real Roman Urdu / Urdu traffic.
